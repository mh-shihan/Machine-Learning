# Imputing Numerical Data
- Mean/Median Imputation
- Arbitarary Value Imputation (Fill with any value)
- End of Distribution Imputation (Fill with max or min value)
- Random Sample Imputation (Fill with random sample from the column)

# Arbitrary Value Imputation
Filling missing values with an arbitrary value. This is useful when we want to treat missing values as a separate category. For example, if we have a column for 'Age' and we fill missing values with -1, we can treat -1 as a separate category indicating that the age is unknown.

# Benefits of Arbitrary Value Imputation
- It is simple to implement and understand.

# Disadvantages of Arbitrary Value Imputation
- Same ar imputing numerical data.
