# Curse of Dimensionality (COD)
Features are also known as Dimensions. Model's optimal performance is achieved when the number of features is optimal. If the number of features is too low, the model will underfit the data. If the number of features is too high, the model will overfit the data. The curse of dimensionality refers to various phenomena that arise when analyzing and organizing data in high-dimensional spaces that do not occur in low-dimensional settings such as the three-dimensional physical space of everyday experience.


## High-Dimensional Space
1. Image
2. Text

## Problems with High-Dimensional Space
1. Performance Decreses
2. Computational Cost

## How to Solve
1. Reduce the number of features using feature selection techniques.
